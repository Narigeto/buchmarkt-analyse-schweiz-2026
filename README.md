# Buchmarkt Analyse Schweiz 2026

Interaktive und präsentierbare Analyse des Schweizer Buchmarkts 2026.

Die Website ist als statische Einzelseite umgesetzt und wird kostenlos über GitHub Pages veröffentlicht.

## Inhalte

- Visuelle Zusammenfassung der Marktanalyse
- Vollanalyse mit Methodik und Detailtabellen
- Transparente Quellenübersicht
- Vorbereitete Navigationsbereiche für Businessplan, Wachstumsideen, Digitalisierung und Organisation

## Veröffentlichung

GitHub Pages stellt die Datei `index.html` aus dem Standard-Branch bereit. Eine Custom Domain wird über die Repository-Einstellungen und die Datei `CNAME` angebunden.
